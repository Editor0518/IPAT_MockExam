# 산업재산권법 모의고사 (개인 학습용)

2026년 제63회 변리사 1차시험 1교시 산업재산권법(A형) 40문항을 모바일에서 풀어 볼 수 있는 한 페이지짜리 웹앱입니다.

## 사용법

- `index.html` 하나로 동작합니다(문제·해설 데이터 내장, 외부 의존성 없음). 휴대폰 브라우저에서 열면 됩니다.
- 진행 상황과 지난 기록은 브라우저 `localStorage`에 저장됩니다. 새로고침하거나 앱을 닫았다 열어도 이어서 풀 수 있습니다.

## 기능

- 40문항 기준 50분 타이머. 문제가 화면에 있고 답을 고르기 전까지만 흐르며, 해설을 보는 동안과 일시정지·앱 전환 중에는 멈춥니다.
- 50분을 넘기면 초과 시간이 계속 표시됩니다.
- 답을 고르면 PDF 해설(판단·해설·근거, 최종 정답, 정답 검증 문구)을 그대로 보여줍니다. 12번은 복수정답(④·⑤)을 모두 인정합니다.
- 결과 화면: 점수, 문항별 풀이 시간, 영역·과목·문제 형식·출제 근거별 정답률과 평균 시간, 강점·약점, 오답 문제 유형, 시간 분석.
- 오답만 다시 풀기(제한 시간 문항당 1분 15초).

## 구조

- `src/app.html` — 화면·스타일·스크립트 원본
- `data/questions.json` — PDF에서 추출한 문제·해설 데이터
- `tools/build.py` — 위 두 파일을 합쳐 `index.html` 생성 (`python3 tools/build.py`)
